# Support

Partizan is an alpha research preview. Support covers the documented bounded
domains and release-candidate installation paths.

Use GitHub issues for:

- reproducible defects;
- documentation errors;
- certificate or schema inconsistencies;
- clean-install failures; and
- bounded-domain research-validity reports.

Include the operating system, Python and Rust versions, Partizan commit or
release, exact command, smallest input, complete error, and any relevant
artifact digest. Remove credentials, private paths, and unpublished data.

General CGT tutoring, unrestricted chess solving, custom experiment execution,
and guarantees outside the documented domain do not have a response-time
commitment. Security-sensitive reports follow [`SECURITY.md`](SECURITY.md).
