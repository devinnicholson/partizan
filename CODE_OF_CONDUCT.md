# Community conduct

Project discussions should remain technically specific, respectful, and open
to correction. Participants are expected to:

- address evidence and arguments without personal attacks;
- distinguish executable results, interpretations, and speculation;
- report errors and negative results directly;
- respect privacy, attribution, licenses, and disclosure boundaries; and
- avoid harassment, discrimination, threats, spam, or deliberate disruption.

Maintainers may edit or remove abusive content and may restrict participation
when conduct repeatedly interferes with safe technical collaboration. Report
conduct concerns privately to the address in the repository owner's verified
GitHub profile with the subject `Partizan conduct report`. The maintainer will
review the available evidence, protect private information, and communicate any
action to the affected participants when appropriate.
